# CEU - Material docente

Repositorio de materiales docentes, enunciados y recursos de apoyo para las asignaturas impartidas en CEU.

## Asignaturas

- [Algoritmos y Estructuras de Datos](algoritmos-estructuras-datos/2026-2027/README.md) - curso 2026-2027
- [Metodología y Tecnología de la Programación](metodologia-tecnologia-programacion/2026-2027/README.md) - curso 2026-2027

## Organización

Los materiales se organizan por asignatura, curso académico, bloque temático y actividad. Cada bloque o actividad incluye el enunciado en PDF, las plantillas que se proporcionen al alumnado y, cuando corresponda, las soluciones publicadas después de la entrega.

## Uso del material

Este repositorio contiene material docente elaborado para la asignatura. Las soluciones pueden permanecer ocultas durante el periodo de realización de una actividad.
