# 01. Introducción a Python

Ejercicios para practicar los fundamentos de Python necesarios antes de comenzar los bloques específicos de algoritmos y estructuras de datos.

## Objetivos

- Trabajar con variables, tipos y operadores.
- Crear y utilizar funciones.
- Recorrer y transformar colecciones.
- Aplicar estructuras de control.
- Validar entradas y gestionar excepciones concretas.

## Actividades

| Actividad | Ejercicios | Contenido principal |
| --- | ---: | --- |
| [Actividad 01](actividad-01/README.md) | 1-5 | Datos, cálculos, decisiones, listas, funciones y calculadora segura |
| [Actividad 02](actividad-02/README.md) | 6-10 | Diccionarios, validación, búsqueda, funciones y programa con menú |

No se requiere programación orientada a objetos ni el uso de librerías externas para estas actividades.
