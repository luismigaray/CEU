# Actividad 02 - Factory Method

Implementación de campos de texto adaptados a móvil y escritorio mediante el patrón Factory Method.

## Enunciado

- [Consultar la guía y el enunciado completo](../enunciado.pdf)
- El ejercicio aparece en el apartado **2.8. Ejercicio para entregar - Factory Method**.

## Trabajo solicitado

Debes definir la interfaz `CampoTexto`, sus implementaciones para móvil y escritorio, una clase abstracta `Formulario` y los creadores concretos `FormularioMovil` y `FormularioEscritorio`.

El programa principal utilizará los formularios sin crear directamente objetos `CampoTextoMovil` ni `CampoTextoEscritorio`.

## Entrega

Esta actividad se entrega de forma independiente en la fecha indicada en clase. La decisión sobre qué campo de texto crear debe permanecer dentro del Factory Method.

Las soluciones se publicarán en la carpeta [`soluciones/`](soluciones/README.md) después del periodo de entrega.
