# Actividad 01 - Singleton

Implementación de una configuración compartida entre distintas pantallas de una aplicación Java.

## Enunciado

- [Consultar la guía y el enunciado completo](../enunciado.pdf)
- El ejercicio aparece en el apartado **1.4. Ejercicio para entregar - Singleton**.

## Trabajo solicitado

Debes crear una única instancia de `ConfiguracionInterfaz` utilizando el patrón Singleton. La configuración almacenará el idioma y el tamaño de fuente, y será utilizada por `PantallaInicio` y `PantallaAjustes`.

El programa principal deberá modificar la configuración y demostrar que las dos pantallas acceden al mismo objeto.

## Entrega

Esta actividad se entrega de forma independiente en la fecha indicada en clase. No es necesario utilizar una biblioteca gráfica; la interfaz se representa mediante mensajes por consola.

La solución comentada y los archivos Java están disponibles en la carpeta [`soluciones/`](soluciones/README.md).
